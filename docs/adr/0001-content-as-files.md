# 内容改成仓库里的文件，不再用数据库和后台

网站首先是给自己用的个人空间，内容主要靠在对话里让 Claude 改。网页后台一直没人用，从国内网络打开又慢。所以内容改成仓库里的文件（参考 Yuniverse 的做法）：Claude 改文件、提交，然后发布。修改历史和撤销交给 Git，不再需要数据库、后台、登录和修改记录表。

## 考虑过的方案

- **保留数据库和后台**：改动即时生效，已经有修改历史、撤销和整套测试。没选这个，是因为后台没人用，维护成本却一直在。

## 后果

- 每次改动都要重新发布才生效，不再是即时的。
- 仓库是公开的，提交进去的内容都会公开。周记、草稿这类私密内容放在本机一个不提交的 `private/` 文件夹里。
- AIHOT 资讯以前只在后台显示，因为条款不允许公开转载。去掉后台以后，网站里不再放它，想看直接上 aihot.news。
- 发布方式：推到 GitHub 后由 Cloudflare 自动构建上线，不依赖本机连 Cloudflare 的网络。
